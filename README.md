# Sistema Web Universitario

Este proyecto consiste en el desarrollo de un sistema web universitario, elaborado de manera colaborativa por un equipo de estudiantes usando Git y GitHub.

## Integrantes

- Integrante 1: Líder del proyecto
- Integrante 2: Desarrollador Frontend
- Integrante 3: Desarrollador Frontend
- Integrante 4: Desarrollador Backend
- Integrante 5: Desarrollador Backend

## Objetivo

Desarrollar un sistema web básico que permita aplicar buenas prácticas de control de versiones mediante GitHub.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
